# LoadMatch Live

Работещ MVP за marketplace за товари и шофьори.

## Локално
Node.js 20+

npm install
SESSION_SECRET="сложи-дълга-случайна-стойност" npm start

Отвори http://localhost:3000

## Включено
- регистрация и вход
- Клиент / Шофьор
- SQLite база
- публикуване и търсене на товари
- кандидатстване
- приемане на шофьор през API
- 10% комисиона
- статистика
- health endpoint `/health`

## Публикуване
Проектът е подготвен за Node hosting (например Render/Railway/Fly.io). Задай `SESSION_SECRET` като secret/environment variable и използвай постоянен диск/managed database за production, защото локалният SQLite файл не трябва да се пази на ефимерна файловата система.

Това е технически MVP. Преди реални платени курсове са нужни условия за ползване, политика за поверителност, верификация на превозвачи, плащания, логове/мониторинг, backups и правен/данъчен преглед.
